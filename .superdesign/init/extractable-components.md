# Extractable components
## AppHeader
- Source: `src/components/AppHeader.js`
- Category: layout
- Description: Persistent top bar with screen title and menu icon
- Extractable props: title (string, default "Dashboard")
- Hardcoded: icons, styles
## TabBar
- Source: `src/components/TabBar.js`
- Category: layout
- Description: Floating bottom dock with 5 tabs + quick actions
- Extractable props: activeItem (string, default "Dashboard")
- Hardcoded: icon names, labels, grey dock surface
